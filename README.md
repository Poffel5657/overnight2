# Overnight 2

A small browser MMO that grows every night at midnight. Version 2 of [Overnight](https://github.com/Poffel5657/overnight).

A village called Kindle stands in a clearing, in an endless grey fog. Every night the fog pulls back a little, and something new is waiting there in the morning.

Still being built. See `DESIGN.md`, `STORY.md` and `DAY0.md`.
